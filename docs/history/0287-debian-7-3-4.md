# 0287 — Debian's 7.3.4 added next to 7.3.3

Date: 2026-11-12. Work started about 11:00 Brasília time. Status: **in progress; test runs
under way on the test host.** Estimated effort S (hours of work, most of a machine day); the time
recorded is calendar time of one session.

## Goal

On 2026-11-12 Debian's sid replaced `linux` 7.3.3-1 with 7.3.4-1 and dropped
`linux-image-7.3.3+deb14-amd64` (journal 0284). A host that installs Debian's 7.3 now gets
`7.3.4+deb14-amd64`, a release the project never tested, while CI keeps 7.3.3 working only
through snapshot.debian.org.

## Decision (maintainer, 2026-11-12, about 10:55 Brasília time)

The maintainer approved moving the support to 7.3.4. How: add Debian's `7.3.4+deb14-amd64` as a supported kernel under rule 3 of
`docs/compatibility.md`, with the same evidence 7.3.3 had: the full suite on Debian's build, the
full suite under KASAN, UBSAN and lockdep on upstream 7.3.4, and fstests `quick` on the three
lowers over upstream 7.3.4 built with `vm/fstests.config`.

Alternatives: replacing 7.3.3 with 7.3.4 in the same change was set aside, because rule 3 removes
a kernel only with a changelog announcement one release ahead; a host that installed Debian's 7.3
before 2026-11-12 still runs 7.3.3. Moving the existing KASAN 7.3 leg to 7.3.4 was set aside for
the same reason: 7.3.3 would lose its KASAN leg while still supported. CI gains one native job and
one KASAN leg; both 7.3 releases stay until 7.3.3 is removed.

## Decision on review records (maintainer, 2026-11-12, about 14:45 Brasília time)

`AGENTS.md` gains a rule: a journal that records a code review, or a finding from one, says who
reviewed, by role, and whether an AI assistant was used, naming the tool, or that it is not known.
Reason: the journals of the reviews in Part B of `docs/review-findings.md` (journals 0082 and
0083, among others) do not say whether those sessions were AI-assisted, and the maintainer does
not remember; that cannot be recovered now.

## Change

- `vm/Dockerfile`, `vm/run.sh`, `vm/in-container.sh`: `MOOB_DEBIAN_KERNEL=7.3.4` installs
  `linux-image-7.3.4+deb14-amd64` and its headers, `7.3.4-1`, on the same sid base as 7.3.3, from
  snapshot.debian.org at `20261112T000000Z`, so the build keeps working when sid moves on.
- `.github/workflows/ci.yml`: a `Native Linux VM (Debian 7.3.4)` job.
- `.github/workflows/kasan.yml`: a fourth leg, `Layer suite under KASAN/lockdep (7.3.4)`, with
  `KERNEL734_VERSION` and `KERNEL734_SHA256`; `vm/kasan-local.sh` takes `MOOB_KASAN_KERNEL=7.3.4`;
  `scripts/check-pins.sh` checks the new pin against kernel.org's `sha256sums.asc`.
- No change under `layer/`: `layer/moobl_compat.h` keys on the 7.3 series.
