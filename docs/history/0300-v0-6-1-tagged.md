## Decisions (maintainer, 2026-11-17)

- About 08:20: cut the tag now, then the `.deb` packages as a separate step.
- The version is `0.6.1`, a patch. Since `v0.6.0-experimental` the kernel changed only by the fix
  of ADR-0040; the rest is tests (S12, journal 0298), the tag checklist and documents. The UAPI
  header and the on-disk conventions did not change. By the rule of journal 0284 (Semantic
  Versioning: a patch for backwards-compatible bug fixes, a minor for new functionality) this is a
  patch. Alternative: `0.7.0`; not taken, since nothing adds functionality.
- Issue #195's route is pinned to `v0.6.1-experimental` instead of `v0.6.0-experimental`: a
  reproduction should run the tag with the fix, and the route's steps do not change. The
  maintainer edits the issue body after the tag (checklist step 12).
