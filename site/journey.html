Journey

Every work session of the project is recorded in a journal: what was asked, what was decided, what was tested and what failed. This page picks the milestones. The full list is the journal index.

  1. 2026-10-10

    The question: can the filesystem carry an agent's memory fields and answer queries on them? A native read-only module comes first.

    journal 0001 · journal 0002

  2. 2026-10-10

    Change of course: a stacked layer over ext4, btrfs and XFS instead of a new on-disk format (ADR-0007).

    journal 0010 · journal 0011 · journal 0012

  3. 2026-10-10

    Typed attributes validated in the kernel; the first in-memory index and attribute query.

    journal 0013 · journal 0014

  4. 2026-10-10

    Our own KASAN and lockdep kernel, from the start.

    journal 0016

  5. 2026-10-11

    Queries scoped by directory and authorized by file permissions: per-domain partitions and the homogeneity rule (ADR-0009).

    journal 0034 · journal 0035

  6. 2026-10-12

    Measured against SQLite on the same machine: faster on filtered conjunctions, slower on long ordered traversals.

    journal 0047

  7. 2026-10-12

    A written threat and credential model, the contract every review is judged against (ADR-0011).

    journal 0060

  8. 2026-10-12

    A security finding fixed: a write to a set-user-ID file crashed the kernel.

    journal 0069

  9. 2026-10-13

    A real memory client on the layer: equal answers from 150 to 60 000 memories.

    journal 0068 · journal 0088

  10. 2026-10-13

    fstests' quick group passes over the three lower filesystems; systematic allocation-failure injection.

    journal 0091 · journal 0096

  11. 2026-10-13

    The alternative without a kernel module, measured honestly; the module stays, its costs go.

    journal 0094 · journal 0095

  12. 2026-10-13

    First answers from the kernel community, and the decisions that followed.

    journal 0097

  13. 2026-10-14

    An index built on demand and released under memory pressure (ADR-0012).

    journal 0098 · journal 0101

  14. 2026-10-14

    SELinux shows the limit of the homogeneity rule; fixed.

    journal 0104

  15. 2026-10-14

    SQL over a domain through a SQLite virtual table (ADR-0013).

    journal 0108

  16. 2026-10-14

    syzkaller over the layer: a reference leak found and fixed; two six-hour runs.

    journal 0109 · journal 0112

  17. 2026-10-19

    A measurement method with intervals finds a roughly 2x query regression; reusing the query buffer fixes it.

    journal 0134 · journal 0139

  18. 2026-10-20

    v0.4.1-experimental published; a fifth six-hour syzkaller run reports no crash and reaches 88.7% aggregate handler coverage, with xattr-get coverage still unexplained.

    journal 0142 · journal 0143

  19. 2026-10-25

    Unprivileged domain builds gain experimental work, time and frequency limits, then a per-mount index_build_work choice (default 32,768; range 1,024–65,536). Issue 118 stays open (ADR-0019, ADR-0020).

    journal 0182 · journal 0193

  20. 2026-10-27

    Issue 118 closed: over a lower slowed to 400 ms per I/O the first build of a domain stops at its deadline with no partial answer.

    journal 0210

  21. 2026-10-28

    Three kernel defects reported privately by an external reviewer are fixed through private advisories: search-only directories (F15), records of a reused inode number, set-user-ID kept through a write (F16, the reviewer's own fix).

    journal 0215 · journal 0216 · journal 0218 · journal 0219

  22. 2026-10-28

    A third batch: F17 (a minimal ACL written outside the VFS) fixed; issues 119 (lookup errnos, the reserved byte of a query term, one privilege test) and 115 (fadvise, readahead, statx fields, drop_inode, O_NOATIME) closed; issue 117 fixed for inodes without an index record.

    journal 0221 · journal 0222 · journal 0223 · journal 0224

  23. 2026-10-28

    v0.5.0-experimental published, with every correction up to that date: F1 to F17 except the fair shares of F2. Its source archive is the first one signed (Sigstore) and with SLSA provenance.

    journal 0226

  24. 2026-10-28

    Fair shares of the index budget: a uid above its share lends its room back to a uid below its own, which closes finding F2; G2's latency ceiling is registered first and then met beside a noisy neighbour in three runs.

    journal 0228

  25. 2026-10-29

    Experimental Debian packages: DKMS builds the module only for the listed kernels and signs it with the host's own key; under Secure Boot in a VM it loads once that key is enrolled, and an unsigned build is refused. Not published.

    journal 0229

  26. 2026-10-30

    fstests' auto group runs once over ext4, btrfs and XFS below the layer, with no defect of the layer among its failures; a sixth six-hour syzkaller run, with no report, covers every handler function, xattr-get included, at 84.5% of the handlers' PCs.

    journal 0239
